## 💻 Sobre o projeto

O **My Beloved Smart Library** é um projeto pessoal que tem como objetivo desenvolver uma aplicação voltada para gerenciamento e avaliação de leituras, bem como auxiliar na revisão do material seguindo a lógica da curva de retenção de Ebbinghaus 
<br><br>
<img width="40%" alt="Curva de aprenziado de Ebbinghaus" src="https://jorgeaudy.com/wp-content/uploads/2014/09/ebbinghaus.png">

## 🛠 Tecnologias

Este projeto possuirá várias implementações de modo a explorar diferentes tecnologias e Frameworks e arquiteturas para Front-End e Back-End e contará sempre com uma sub-aplicação ou módulo para servir como a API de comunicação entre os serviços. 

## 🎨 Implementações do Front-End:
-  **Java Server Pages (JSP)**
## 📚 Bibliotecas Utilizadas
- **Implementação:** Java Server Pages (JSP) **|** **Biblioteca:** Jakarta Servlet API
<br><br><br>

## 🛠 Implementações do Back-End:
-  **Java Database Connectivity JDBC**
## 📚 Bibliotecas Utilizadas
- **Implementação:** Java Database Connectivity JDBC **|** **Biblioteca:** J-Unit 6 para testes unitários
- **Implementação:** Java Database Connectivity JDBC **|** **Biblioteca:** PostgreSQL escolhido como banco de dados relacional
<br><br><br>

## 🛠 Implementações de DevOps:
- **Implementação:** Todas **|** GitHub Actions para esteira de integração contínua
- **Implementação:** Todas **|** Docker & Docker Compose para conteinirização e empacotamento dos artefatos

## 🛠 Funcionalidades
- Persistência de avaliações sobre leituras recentes, comportando um resumo em PDF para facilitar o reforço na assimilação do conteúdo
- (Desejada) envio de E-mails lembrete através da API do Gmail
- (Desejada) interação com a API do Notion para persistência em uma paǵina utilizada como tabela/base de dados, possibilitando acesso imediato após qualquer alteração em qualquer dispositivo
